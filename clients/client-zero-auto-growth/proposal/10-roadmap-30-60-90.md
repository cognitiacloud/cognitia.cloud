# 30 / 60 / 90-Day Roadmap — Auto Growth OS

A credible path with a **fast first win**. The sequence adapts to the discovery
config: we always fix the client's biggest leak (`primary_goal`) first, then
build outward. Dates are working-day targets from kickoff, not guarantees of
outcome.

> Guardrails: milestones below are _work delivered_. We do not schedule a
> guaranteed sale, ranking, or lead count. Finance/trade-in flows go live only
> after the named approver signs off (`[REQUIRES HUMAN APPROVAL]`). See
> `../internal/guardrails.md`.

---

## Phase 0 — Kickoff (Days 0–5)

| Milestone             | Output                                                                     |
| --------------------- | -------------------------------------------------------------------------- |
| Kickoff call + access | Inventory source, brand assets, channel access collected                   |
| Config locked         | Discovery Console config confirmed → package + modules                     |
| Baseline captured     | Current response time, weekly inquiries, days-on-lot recorded (proof plan) |
| Approver named        | Finance/trade-in sign-off owner confirmed                                  |

## Phase 1 — Days 1–30: Foundation + first leak fixed

Goal: **stop the biggest leak fast and get something live.**

| Workstream           | 30-day target                                                                                             |
| -------------------- | --------------------------------------------------------------------------------------------------------- |
| Website              | Core site live: home, inventory listing, vehicle detail pages, contact. Fast + mobile.                    |
| Inventory automation | Stock publishing to the site; photo privacy/quality check in the loop.                                    |
| Intake               | One-inbox capture for the top 2 channels (usually WhatsApp + web form). Consent-first templates in place. |
| CRM-lite             | Pipeline stages + lead capture wired; every new lead lands somewhere tracked.                             |
| First win            | The `primary_goal` leak instrumented — e.g. after-hours auto-response live if goal = `faster_response`.   |

**30-day checkpoint:** baseline vs. first 30 days — response time and leads
captured. Honest read-out.

## Phase 2 — Days 31–60: Full pipeline + AI Sales Closer

Goal: **every lead answered fast and worked to a booked appointment.**

| Workstream       | 60-day target                                                                                                                               |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| AI Sales Closer  | Live on primary channels: qualifies, recommends inventory, books test drives, hands off on finance/trade-in. Disclosure + handoff verified. |
| Channels         | Remaining channels from `lead_channels[]` connected to the one inbox.                                                                       |
| CRM-lite         | Follow-up automations + SLA timers on; lost-lead re-engagement (consent-first).                                                             |
| Content          | Vehicle pages enriched; first AEO answer/FAQ content published.                                                                             |
| Finance/trade-in | If in scope: approved collection-and-handoff flow goes live **after sign-off**.                                                             |

**60-day checkpoint:** appointments booked, response time, pipeline conversion by
stage, attribution by channel.

## Phase 3 — Days 61–90: Visibility + optimization

Goal: **be found where buyers look, and tighten what's converting.**

| Workstream   | 90-day target                                                                     |
| ------------ | --------------------------------------------------------------------------------- |
| SEO          | Make/model/location pages built to best practice; schema in place.                |
| AEO/GEO      | Answer content + local/map presence cleaned and structured.                       |
| Optimization | A/B the top vehicle pages and intake flows; cut the worst-performing steps.       |
| Proof        | Full dashboard reviewed; Client Zero case-study data assembled (with permission). |
| Scale plan   | Recommend next 90 days based on what the numbers show.                            |

**90-day review:** baseline → 90-day numbers across the full proof set. Decide
renew/expand scope.

## Adaptive sequencing by primary goal

| `primary_goal`      | What we front-load in Phase 1                              |
| ------------------- | ---------------------------------------------------------- |
| `faster_response`   | AI auto-response + one-inbox intake first                  |
| `more_leads`        | Website + inventory publishing + paid-channel intake first |
| `higher_close_rate` | CRM-lite + follow-up + AI qualification first              |
| `online_presence`   | Website + SEO/AEO foundation first                         |
| `inventory_online`  | Inventory automation + vehicle pages first                 |

The Discovery Console outputs this ordering automatically from the config.
