# 03 — Demandara GTM OS Product Context

Demandara is the AI GTM / Demand Gen / Sales Closer / revenue operating system that runs on Cognitia controls.

## Demandara must become better than Alta by combining

- Alta-style prospecting/inbound/revenue intelligence;
- vertical-native adapters;
- proof receipts;
- human approval gates;
- Demand Gen SEO/AEO/AIO engine;
- connector registry;
- model-router brain harness;
- agent passports/work events;
- monthly proof-backed revenue reports;
- outcome-first metrics, not just meetings booked.

## Product modules

| Module                     | Purpose                                                                |
| -------------------------- | ---------------------------------------------------------------------- |
| Lead intake                | Normalize inbound/referral/manual/demo leads.                          |
| Qualification              | Score avatar fit, urgency, trust gap, and next step.                   |
| Sales Closer               | Run governed CLOSER-informed lead progression.                         |
| Trust gate                 | Apply Cognitia policy, consent, and approval rules.                    |
| Vertical adapter           | Specialize workflow for dealer, mover, education, finance/media lanes. |
| Connector registry         | Describe safe connectors without enabling live egress.                 |
| Model router brain harness | Select/replay mock model tasks with fail-closed routing.               |
| Command Center             | Operator view of pipeline, approvals, proof, and blockers.             |
| Proof reporter             | Monthly proof-backed revenue report and per-lead receipt.              |

## Outcome metrics

Optimize for qualified lead progression, consented follow-up readiness, human-approved next steps, proof receipts generated, blocked unsafe action count, revenue opportunity preserved, and monthly proof-backed report quality. Do not optimize only for meetings booked.
