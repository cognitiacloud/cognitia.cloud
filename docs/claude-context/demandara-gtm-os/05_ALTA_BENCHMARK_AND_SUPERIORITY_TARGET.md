# 05 — Alta Benchmark and Superiority Target

## Boundary

Alta is a benchmark, not a parity claim. Demandara is held at `ALTA_HELD_AT_60` until implementation, tests, integration, and independent review support movement.

## Demandara target

Demandara must become better than Alta by combining Alta-style prospecting/inbound/revenue intelligence with vertical-native adapters, proof receipts, human approval gates, Demand Gen SEO/AEO/AIO, connector registry, model-router brain harness, agent passports/work events, monthly proof-backed revenue reports, and outcome-first metrics.

## Gap matrix

| Capability           | Alta-style expectation          | Demandara target                                          |
| -------------------- | ------------------------------- | --------------------------------------------------------- |
| Prospecting          | Find/enrich prospects           | Add source-rights proof and vertical context.             |
| Inbound              | Handle/route interest           | Qualify with consent and human approval.                  |
| Revenue intelligence | Score likelihood/opportunity    | Track outcome-first proof metrics and monthly reports.    |
| Agent system         | AI workers execute tasks        | Agent passports, action ledger, and blocked-action proof. |
| Integrations         | CRM/email/enrichment connectors | Connector registry with deny-by-default live execution.   |
| Reporting            | Activity/meetings pipeline      | Proof-backed revenue reports, not vanity activity.        |
| Governance           | Enterprise controls             | Cognitia TrustOps is the moat.                            |

## Claim-safe wording

Allowed internal target line: Demandara is being designed to outperform generic AI GTM tools by combining GTM execution with vertical-specific workflows and proof-backed governance.

Forbidden: “Demandara is already better than Alta,” “Demandara is production-ready,” or “Demandara can contact customers now.”
