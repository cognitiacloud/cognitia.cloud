# SOC 2 Evidence Checklist (V1)

> Concrete artifacts an auditor will ask for, where they live, and cadence. Pair with
> `control-matrix.md`. Goal: a Type 1 point-in-time set, with automation so the Type 2
> window accrues continuously. Onboard a compliance tool (Vanta/Drata) day 1.

## A. Automated/continuous (wire once, collects forever)

- [ ] **CI run** of `kysely.rls.pglite.test.ts` (tenant isolation, non-superuser) — every build. _Where:_ CI logs / required check.
- [ ] **CI run** of idempotency + approval-refusal tests — every build. _Where:_ CI logs.
- [ ] **PII/secret redaction** test (`logging.test.ts` + no-token-in-log) — every build.
- [ ] **Branch protection** on the release branch (review + required checks). _Where:_ GitHub settings export.
- [ ] **Dependency/secret scanning** on PRs. _Where:_ scanner dashboard.

## B. Point-in-time configuration evidence (capture at go-live, re-capture on change)

- [ ] DB role config proving app traffic uses **`app_user` (non-superuser)**.
- [ ] KMS key policy + **rotation <90d** log.
- [ ] TLS/load-balancer config (in transit) + storage-encryption attestation (at rest).
- [ ] HubSpot app **scopes** screenshot (least privilege) + idempotency property exists.
- [ ] Backup/PITR config + **one tested restore** record.
- [ ] Schema-version gate on API boot.

## C. Documents / policies (versioned, signed)

- [ ] Information security policy, access control policy, change management policy.
- [ ] Incident response runbook (`runbooks/incident-response.md`) + ≥1 **drill record**.
- [ ] Access review (`runbooks/access-review.md`) — first review completed + signed.
- [ ] Data retention + deletion/DSAR policy.
- [ ] Sub-processor register + signed DPAs.
- [ ] Vendor risk assessments; annual risk assessment.
- [ ] Security training + onboarding/offboarding records.
- [ ] Pen-test report + remediation tracker (GA).

## D. Operational evidence (generated by the product)

- [ ] **Audit-trail export** sample: a contact's full propose→approve→execute chain.
- [ ] **Kill-switch** demonstration: paused connection halts execution.
- [ ] Monitoring dashboards screenshot (`*.failed.v1`, sync_run, heartbeat).
- [ ] Sample structured logs proving **no raw PII/tokens**.

## Storage & ownership

- **Owner:** Compliance (with ENG-platform for technical evidence).
- **Store:** the compliance tool's evidence vault; link from `control-matrix.md`.
- **Cadence:** automated (every build) · config (on change) · policies (annual review) · access review (quarterly) · drill (quarterly).

## Type 1 vs Type 2

- **Type 1** = controls _designed and in place_ at a point in time → the above, captured once, is sufficient to engage.
- **Type 2** = controls _operating effectively over 3–6 months_ → requires the automated (A) + cadence (C/D) evidence to accumulate across the window. **Cannot complete inside 90 days; start the window early.**
