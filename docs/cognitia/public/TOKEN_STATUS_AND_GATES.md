# Token Status and Gates

Public-safe explainer of Cognitia's token status. This page makes no offer, no
solicitation, and no investment statement of any kind.

## Status (plain)

- **No public token exists.**
- The token is **not launched**.
- There is **no liquidity**, **no DEX**, **no staking or yield** product.
- There is **no launch date**.
- **The token may never launch.** It is optional by design.

## How value moves today

- Settlement is in **internal credits**: a double-entry, append-only accounting
  ledger, **non-transferable** outside the tenant ledger. Credits are **not
  money** and **not a token**.
- Where external settlement is ever needed, the design favors **credits first**,
  then conventional rails / stablecoins under the appropriate legal gate — never
  a speculative token as the payment mechanism.

## What would have to be true before any token

A future token would only proceed if **all** of these gates pass (none are passed
today):

1. **Legal** — counsel opinion (e.g. Canada/BC + US) that the design is lawful and
   not an unregistered security.
2. **Usage** — the platform economy demonstrably works and is used first; utility
   is earned, then mapped — never the reverse.
3. **Utility** — a real, non-speculative function (see below).
4. **Multi-tenant** — cross-boundary trust/settlement actually requires it.
5. **Security / audit** — external audit completed.
6. **Communications** — disciplined, non-promotional, compliant messaging.

## What a token would (and would not) be

- **Would** only be **assurance collateral**: a bond posted by verifiers,
  publishers, workers, or arbiters that is **slashed** for proven bad work —
  value that must be _at risk_ to mean anything, which non-transferable internal
  credits cannot provide across trust boundaries.
- **Would not** be a SaaS checkout currency. Ordinary product usage does not
  require a token.
- **Would not** be tied to any single vertical (e.g. MoverOS) alone. If it ever
  exists, it belongs to the broader **agent economy**, not one product.
- **Would not** carry yield, APY, passive income, or any return.

## Restated

No public token, no sale, no purchase path, no price, no return, no exchange
listing. The gates — not product demand or distribution — are the only thing that
could ever unlock a token, and they remain **NOT PASSED**.
