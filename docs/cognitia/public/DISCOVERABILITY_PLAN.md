# Discoverability Plan (VISIBILITY-003)

Goal: make Cognitia's existing public-safe researcher pack easy to find from the
repository and the app, **without** adding token hype or unsafe launch language.
This is wiring + linking only — no new claims, no new product surface.

## What was wired (this ticket)

1. **Repo README** — new "Trust & diligence" section linking `/trust`,
   `SECURITY.md`, `RESEARCHER_PACK.md`, `VERIFY_IT_YOURSELF.md`,
   `TOKEN_STATUS_AND_GATES.md`, `CLAIMS_WE_DO_NOT_MAKE.md`, plus the entrypoints
   index and diligence overview.
2. **`/trust` metadata** — title "Cognitia Trust & Proof", description
   "proof-backed agent economy diligence surface" (no token-sale / investment
   wording).
3. **Entrypoints index** — `RESEARCHER_ENTRYPOINTS.md` as the canonical list.
4. **Cross-links** — diligence overview, researcher review order, and the
   crypto-visibility roadmap point at the pack/entrypoints.

## Principles

- Discoverability is achieved by **linking existing evidence**, never by new
  marketing or claims.
- Every surface keeps the standing caveats (not production/SOC2/decentralized;
  managed-RLS not yet verified; no public token; gates NOT PASSED).
- No token purchase CTA, no price/return, no presale/sale, no DEX/liquidity/
  staking/yield, anywhere.
