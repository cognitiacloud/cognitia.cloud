# Safe Public Narrative (LOOP 4)

The canonical, public-safe way to describe Cognitia. Reuse this wording verbatim
across docs and surfaces so the story is consistent and survives diligence.

## One line

**Cognitia is the proof-backed trust layer for the agent economy.**

## Short paragraph

As software agents start to act and transact, the scarce thing is trust: who an
agent is, what it can actually do, whether it really did the work, and what it's
owed. Cognitia gives agents a verifiable identity, provable skills, an append-only
record of proven work, escrowed task settlement that releases only against
verified evidence, and earned, portable reputation. It is built to compose with
emerging agent standards (identity, payments, interoperability), and it runs
today as a runtime-verified internal economy — no token required.

## Supporting beats (each is repo-backed)

- **Verifiable identity** — ATC (issuer/subject/claims/status; revocation terminal).
- **Provable capability** — SkillProof tiers; higher tiers require verified evidence.
- **Proven work** — append-only Proof Registry; every claim is evidence-tagged.
- **Honest value movement** — escrow releases and reputation move ONLY on a
  `verified_fact`; weak evidence moves nothing.
- **Accountability** — disputes with owner arbitration + resolution proofs.
- **Composability** — designed to map onto ERC-8004 / x402 / W3C VC / MCP / EAS.
- **Restraint** — internal, non-transferable credits today; any future token is
  optional, legal- and usage-gated, and only ever assurance collateral.

## Resilience beat (sober — see LANE_R)

Cognitia researches a resilient agent fabric: user-owned compute with local-or-
cloud routing and portable, verifiable proof of work — to reduce single-vendor and
single-jurisdiction dependency. (Continuity and sovereignty, never evasion.)

## Tone rules

- Lead with evidence and restraint. Invite scrutiny ("verify it yourself").
- Name the open gaps (team, audit, traction) rather than hiding them.
- Never use price, return, sale, yield, or "get in early" framing.

## Do-not-say (see UNSAFE_LANGUAGE_BLACKLIST.md)

"next Ethereum/Solana", "get in early", "presale/public sale", "APY/yield/passive
income", "guaranteed/expected returns", "impossible to shut down", "decentralized
and uncensorable" (as fact), "production-ready", "SOC 2 certified", "audited".
