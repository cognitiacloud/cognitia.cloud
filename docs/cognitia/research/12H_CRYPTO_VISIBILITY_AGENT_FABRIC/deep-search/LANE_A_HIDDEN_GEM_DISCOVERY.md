# LANE A — Hidden-Gem Discovery (how researchers find early projects)

**Objective**: How serious researchers (not price-chasers) discover credible
early-stage crypto/AI-crypto projects.

**Sources used (WebSearch)**: ICO/gem-hunter checklists; "spotting red flags in
new coins 2026" (vedb.me); due-diligence guides (manimama.eu); general practice.
Egress note: titles/URLs only; treat single snippets as `likely_inference`.

## Findings
- `likely_inference` — Discovery that survives diligence is **builder-signal-first**:
  active public code, real commits/tests/releases, credible docs, standards
  participation, technical write-ups, and practitioner discussion — *before*
  exchange/price chatter.
- `likely_inference` — Price/influencer-led discovery correlates with the worst
  outcomes (pump-and-dump, rug). Researchers explicitly discount it.
- `verified_fact` — Cognitia is discoverable through code + docs today: a public
  repo with 490 passing tests, append-only proofs, and an architecture lock —
  exactly the builder-signal surface.

## Relevance to Cognitia
Cognitia should be *findable the way researchers actually look*: GitHub activity,
a clean README that links the evidence, standards alignment (MCP/ERC-8004/x402),
and a public diligence overview. It should NOT chase price/influencer discovery.
