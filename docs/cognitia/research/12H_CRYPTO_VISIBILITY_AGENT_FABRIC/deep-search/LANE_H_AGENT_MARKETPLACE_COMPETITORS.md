# LANE H — Agent Marketplace / Trust Competitors

**Objective**: The competitive landscape for agent trust, payments, reputation,
and marketplaces.

**Sources (WebSearch)**: base.org agentic economy; x402.org ecosystem; ERC-8004
guides; arXiv multi-agent economy papers; general landscape knowledge.

## Landscape (categories, not endorsements)
- **On-chain agent identity/reputation**: ERC-8004 registries + ecosystem tooling
  (the standard layer Cognitia maps to, not a direct product competitor).
- **Agent payment rails**: x402 facilitators (Coinbase, Cloudflare, Google per
  reporting); stablecoin rails. Payments, not trust/work-proof.
- **Agent frameworks/orchestration**: LangGraph, CrewAI, n8n-based agent stacks
  (orchestration, not proof-backed economy).
- **Agent marketplaces**: emerging skill/agent marketplaces (discovery, usually
  without verified-work escrow + dispute + portable reputation).

## Findings
- `likely_inference` — Most entrants own ONE layer (identity OR payments OR
  orchestration OR a marketplace). Few combine **identity + capability proof +
  append-only execution receipts + reputation + escrowed work + disputes** as one
  coherent, test-backed system.
- `likely_inference` — Cognitia's differentiation is the *integration* and the
  *evidence discipline* (only verified_fact moves value/reputation), not any single
  primitive.

## Relevance to Cognitia
Position Cognitia as the **trust + proof + settlement layer** that complements
(not competes with) standards/payment rails (ERC-8004/x402) and frameworks.

## Gaps
- No public competitive/positioning page; no explicit "how we differ" doc.
- No demonstrated interop with the standard layers yet (design-only).

## Recommended actions

## Unsafe claims to avoid
