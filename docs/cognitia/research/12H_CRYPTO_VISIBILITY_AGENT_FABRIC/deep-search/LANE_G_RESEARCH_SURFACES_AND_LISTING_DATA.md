# LANE G — Research Surfaces & Listing Data

**Objective**: The data surfaces researchers consult (CoinGecko/CMC-style, GitHub,
docs, on-chain explorers) — and what Cognitia can honestly populate.

**Sources**: general knowledge of CoinGecko/CMC/DefiLlama/explorer data models;
LANE C sources.

## Findings

- `verified_fact` — Cognitia has **no token**, so there is **no** CoinGecko/CMC
  listing, no market cap, no circulating supply, no on-chain explorer data. None
  of this may be fabricated or implied.
- `likely_inference` — The research surfaces Cognitia _can_ legitimately populate
  today are non-token: GitHub (activity, tests), docs site, a public diligence
  overview, and the `/trust` + `/trust/live` evidence surfaces.
- `likely_inference` — For agent-economy projects, a credible "listing-equivalent"
  is a **public evidence manifest** (what the system proves) + reproducible repo,
  not a token market page.

## Relevance to Cognitia

Direct researchers to the _honest_ surfaces: repo, docs, `/trust`, `/trust/live`.
Treat the absence of token/listing data as a feature (no token to pump), stated plainly.

## Gaps

- No single canonical "project profile" page aggregating the honest surfaces.

## Recommended actions

- Build a public **project profile / researcher pack** index (LOOP 4) linking:
  repo, architecture, evidence manifest, trust explorer, token-gates, FAQ.
- When/if a token is ever launched (gated, far future), only then populate
  listing-style data — with real on-chain backing.

## Public-safe wording

"There is no Cognitia token, market cap, or listing. Evaluate Cognitia via its
code, docs, and verifiable proof surfaces."

## Unsafe claims to avoid

No fake/placeholder ticker, supply, market cap, listing, or 'coming to exchange' language.
