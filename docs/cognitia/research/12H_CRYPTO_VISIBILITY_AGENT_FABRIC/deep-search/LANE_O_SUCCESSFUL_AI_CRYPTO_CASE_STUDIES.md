# LANE O — Successful AI-Crypto Case Studies (what they did right)

**Objective**: Patterns from credible AI-crypto / agent-economy efforts, abstracted
into transferable lessons. (Named projects discussed at the pattern level; treat
specifics as `likely_inference` given egress-limited verification.)

**Sources (WebSearch)**: base.org agentic economy; x402.org ecosystem; ERC-8004
guides; standards bodies (EF, Linux Foundation A2A).

## Patterns that worked (abstracted)

- `likely_inference` — **Standards-first, neutral infrastructure** (e.g. the way
  ERC-8004 and x402 are positioned as open standards, not products) earns broad
  adoption and researcher trust.
- `likely_inference` — **Real usage metrics over promises** (x402's reported
  100M+ payments narrative landed because it was a usage claim, not a price claim).
- `likely_inference` — **Backing by credible orgs / open governance** (EF,
  MetaMask, Google, Coinbase, Linux Foundation involvement) de-risks perception.
- `likely_inference` — **Composability** (do one layer well, interoperate with the
  rest) beats monolithic "do everything" pitches.
- `likely_inference` — **Documentation + developer experience** as a first-class
  product.

## Relevance to Cognitia

Cognitia can borrow: position as neutral infrastructure (trust/proof layer);
publish usage/repro evidence not price; compose with standards; invest in docs/DX.
What it can't yet borrow: brand-name org backing (mitigate via reproducibility +
eventual audit) and on-chain usage metrics (no token).

## Recommended actions

- Lean into "open, reproducible infrastructure" framing.
- When a pilot lands, publish _usage_ evidence (proofs created, work verified),
  never price.

## Public-safe wording

"Cognitia follows the credible playbook: open, reproducible infrastructure that
composes with agent standards — evaluated on usage and evidence, not price."

## Unsafe claims to avoid

No implied partnerships/backing that don't exist; no borrowed credibility; no
price/return comparisons.
