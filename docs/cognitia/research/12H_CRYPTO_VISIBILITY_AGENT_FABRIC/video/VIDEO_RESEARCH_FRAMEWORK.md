## Independent framework (the part a serious researcher checks)

### 1. Discovery (how early projects surface)
Developer-activity signals (active GitHub, real commits/tests/releases), standards
participation (MCP/A2A/ERC-8004/x402), credible docs, technical write-ups, and
practitioner discussion — *before* price/exchange chatter. **Green flag**: you can
read the code and reproduce a demo. **Red flag**: discovery is purely price/influencer-driven.

### 2. Team
Named, reachable builders with verifiable history; public commits; willingness to
answer hard questions. **Red flag**: fully anonymous team + treasury control + no
track record.

### 3. Product / runtime proof
A working product with reproducible behavior, not a deck. **Green flag**: tests
that run, a public demo, append-only evidence of real work. **Red flag**: "coming
soon," screenshots only.

### 4. Tokenomics credibility
Token exists because the system *needs* it (e.g. collateral that must be at risk),
not to fundraise. Clear supply, vesting, no hidden insider unlocks, no yield/APY
bait. **Red flag**: token-first, utility-later, high insider allocation, staking/
yield marketing.

### 5. On-chain / data
For launched tokens: holder distribution, liquidity locks, contract verification,
mint/owner controls. **N/A for Cognitia today — no token exists** (do not fake any
listing/on-chain data).

### 6. Security
External audit, bug bounty, incident response, secrets hygiene, public trust
surfaces. **Red flag**: "audited" with no report; admin keys with no timelock.

### 7. Legal restraint
No investment promises, no "get in early," compliance-aware framing, jurisdiction
awareness. **Green flag**: explicit "this is not an investment; token is gated."

### 8. Catalysts / moat
Defensible primitive (here: proof-backed agent economy), standards alignment,
integrations, real users. **Red flag**: pure narrative with no moat.

### 9. Risk discipline
The project itself names its own unknowns and gates. **Green flag** (rare and
strong): a public "what we do NOT claim" page — which Cognitia already has.
