# 65P-6 — Workflow Breadth Demo Story V2

## Founder demo sequence

1. `retry_scheduled`: the system records a safe next-touch state without sending anything.
2. `follow_up_due`: operator sees the lead is ready for human review.
3. `no_show`: the demo shows recovery logic without booking or messaging.
4. `closed_lost_revival`: the system can represent revival intent, but does not contact anyone.
5. `manual_hold`: human gate blocks the workflow.
6. `completed`: proof trail explains what happened in the local demo.
7. `disqualified`: safe stop, no writeback, no outreach.

## Safe narration

"These are workflow states, not live automations. The local demo shows how Demandara would structure operator decisions before any live channel or CRM integration is approved."
